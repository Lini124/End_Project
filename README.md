1.The Project Overview:

This project focuses on analyzing employee data from ABC company using Python. The main objective is to understand employee distribution across teams and positions, identify the predominant age group, analyze salary expenditure and investigating correlation between age and salary.
The analysis uses Python libraries such as Pandas, Numpy, Matplotlib, Seaborn to preprocess the data, perform calculations, and create visualizations.
Jupyter Notebook is used to write and execute the code.

2. Data Description:

This project uses an Excel file named "ABC COMPANY" which contains a dataset contains employees data with 458 rows and 9 columns.
The dataset includes details such as employee age, team, position, and salary.

3. Data Preprocessing:

The height column has dates and this column has been replaced the "Height" column with random values between 150 and 180.

4. Analysis Task:

a. Employee Distribution by team:

The number of employees in each team was calculated using grouping and counting techniques. The percentage of employees in each team was also calculated to understand how the workforce is distributed across teams.

b. Employee Distribution by position.

The number of employees in each position was calculated to identify the most common postions.

c. Predominant Age group:

The predominant age group is found from the employees categorized age group dataset.

d. Salary Expenditure by team:

The total salary expenditure for each team was calculated by grouping employees by team and summing their salaries. This analysis helps identify the teams with the highest and lowest total salary expenditure.

e. Correlation between age and salary:

The correlation between Age and Salary is calculated and the output is 0.214 which is a weak positive linear correlation.

5. Graphical Representation:

   a. Employee Distribution by team: Bar Chart is used.
   b. Employee Distribution by position: Bar chart is used.
   c. Predominant Age group: Bar chart is used.
   d. Salary Expenditure by team: Bar chart is used.
   e. Correlation between age and salary: Scatter plot is used.

6. Insight Gained:

   a. Team Distribution: Employee counts and percentages help identify teams with larger and smaller workforce representation.
   b. Position Distribution: Position counts reveal which positions are most common in the dataset.
   c. Predominant Age: To get the predominant age group range from the dataset.
   d. Salary Expenditure: Team-level salary totals show how salary expenditure differs across teams.
   e. Correlation : The correlation between age and salary is 0.214

7. Conclusion:

This project demonstrates how Python can be used to analyze employee data and present meaningful findings through visualizations. The analysis covers          distribution, age predomination, salary expenditure, and the relationship between age and salary.
